# Hangar

An aircraft explorer. Browse 124 aircraft across 16 categories (fighters, bombers, airliners, business jets,
private aircraft, helicopters, MALE drones, smaller drones and quadcopters, warbirds, record breakers and more), open any one for its specs,
photo gallery, modeled flight envelope, runway needs and range, and compare up to three side by side.

Live: https://eilonlevin3.github.io/Hangar/

## Run locally

Double-click `start.bat` (needs Python), or run `python -m http.server 8770` here and open http://localhost:8770/.

## Install on iPhone

Open the live link in Safari → Share → **Add to Home Screen** → Add.

## Data and credits

Aircraft figures are approximate published values for the variant named on each page. Flight envelopes are
modeled from those figures with the International Standard Atmosphere and are illustrations only.
Photos and intro text come live from Wikipedia and Wikimedia Commons; each photo shows its author and licence.

See `CLAUDE.md` for how the project is organised and how to change it.
